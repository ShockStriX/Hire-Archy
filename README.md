# EPI-USE Africa Demo Project by Gustav Erasmus
Hire-Archy is a cloud hosted human capital management web-application, aiming to provide 
a clear and functional way to view an organisation’s structure at any scale. Managing 
employee data, viewing hierarchical structure, and managing leave processes have never 
been this easy.
